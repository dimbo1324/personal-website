# Personal Website — план работ

Внутренний документ (русский). Порядок работ задаёт таблица ниже: делается первый
незакрытый шаг. Отступление от порядка — решение владельца в `open-questions.md`.

Исходный макет сайта сохранён как есть в
`docs/__arch__/reference/dmitrii-portfolio-prototype/` (только чтение, ванильные HTML/CSS/JS на
Vite). Это референс дизайна и контента, а не код для копирования.

## Шаги

| --- | ---------------------------------------------------------------------------------------------------------- | ---------------------------------------- |

| W3  | Секции сайта по макету: hero, обзор, опыт, проекты, галерея, досье, подвал; доступность и клавиатура       | открыто                                  |
| W4  | Интерактивные блоки на Vanilla TS: телеметрия, SCADA-панель, театр-режим (по решению владельца, что взять) | открыто                                  |

**Статус W0.** Готово 2026-11-24: правила `.ai/` (универсальные и проектные), `CLAUDE.md`,
`GEMINI.md`, сгенерированный `AGENTS.md`, `.claude/` и `.codex/` (агенты и навыки), TypeScript
xtask (`gate`, `fmt`, `sync-agents`, `doctor` и др.), git-хуки, CI, заглушка страницы со всем
стеком, `POST /api/lead` с Turnstile и Telegram (в тестах — через подменный `fetch`), 21 модульный
тест. Не сделано (ждёт владельца): реальные ключи Turnstile, токен бота Telegram, номер WhatsApp,
подключение Cloudflare Pages к репозиторию — это шаги W5–W6.

**Статус интеграций (2026-11-25).** По указанию владельца добавлен демо-контур:
серверный `StubLeadNotifier` с явным `LEAD_DELIVERY_MODE=stub`, клиентский
`DemoGateway` с `PUBLIC_LEAD_MODE=demo` и настраиваемый канал WhatsApp с режимами
`auto` / `real` / `stub` / `off`. Всё выключено по умолчанию и честно помечено в
интерфейсе. Порядок вывода в бой описан в `docs/__arch__/integrations.md`. Боевая
часть W5 и шаг W6 остаются открытыми.
