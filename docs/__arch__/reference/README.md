# Reference: archived prototype

`dmitrii-portfolio-prototype/` is the original mockup of the site (vanilla HTML, CSS and
modular JavaScript built with Vite), moved here unchanged on 2026-11-24 so the design and
content are never lost.

- Read-only: superseded wherever later decisions differ; do not edit, lint or format it
  (ESLint, Prettier and TypeScript exclude this folder).
- Use it as a reference for layout, copy (EN / ES / RU), motion ideas and assets
  (fonts, images, CV PDFs, OG image tooling). The new site is built in Astro in `src/`.
- Run it on its own if needed: `cd dmitrii-portfolio-prototype && npm install && npm run dev`
  (its own `package.json`, independent of the root project).
