# Security Policy

Report suspected vulnerabilities privately to the repository owner through GitHub's
private vulnerability reporting ("Security" tab → "Report a vulnerability"). Do not open
a public issue and do not include secrets, Telegram bot tokens, Turnstile secret keys or
visitor personal data in a report.

Security guardrails for contributors and AI assistants:
`.ai/project/15-web-and-lead-security.md` and `docs/architecture/invariants.md`.
